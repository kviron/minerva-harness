Minerva Hybrid Icon Pack
========================
This pack combines both versions:
- Small sizes use the simplified Minerva for better readability.
- Large sizes use the detailed Minerva for richer presentation.

Threshold used:
- Simplified: 16, 20, 24, 28, 32, 40, 48, 64 px
- Detailed: 72 px and above

Platform notes:
- Windows ICO includes mixed sizes: 16, 24, 32, 48, 64 (simplified) and 128, 256 (detailed).
- macOS ICNS/iconset uses simplified up to 64 px and detailed from 128 px upward.
- Linux hicolor uses simplified up to 64 px and detailed from 96 px upward.
